# # Kalkulator Efisiensi Turbin Mekanika Fluida

- Cara run di terminalnya: npm install (tapi install node.js dulu)
- Nanti pergi ke server.js terus run: node server.js
- Command diatas baru bisa untuk windows, untuk linux/macOS akan diupdate secara berkala :>
- INDIKATOR WARNA PADA TURBIN:
-*🔵 **Biru Cyan**: Daya Standar ($< 500 \text{ kW}$)
-*🟢 **Hijau Neon**: Daya Optimal ($500 - 2000 \text{ kW}$)
-*🟠 **Amber/Oranye**: Daya Masif ($> 2000 \text{ kW}$)
- Cara diatas cara run di local host yeah
